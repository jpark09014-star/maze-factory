# 베타아빠 미로공장

버튼 한 번으로 새 미로를 만들고, **문제지와 정답지를 A4로 프린트**하는 무료 미로 도안 생성기예요.

- 바로 쓰기(설치 없음): https://jpark09014-star.github.io/maze-factory/
- 윈도우 PC용 exe: [Releases](https://github.com/jpark09014-star/maze-factory/releases/latest)
- 만든 사람: 베타아빠 · 블로그 https://blog.naver.com/geekpapa · 인스타그램 @dad_in_beta

## 할 수 있는 것
- 테마 5가지: 달나라(해→달), 하트, 사과(집→사과), 바다(물고기→별), 꽃길(꽃→해)
- 난이도: 쉬움 9x13, 보통 14x20, 어려움 20x28, 직접(가로 5~30, 세로 7~40칸)
- 한 번에 1~10장. 장마다 다른 미로가 나오고, 문제지를 먼저, 정답지를 뒤에 출력해요
- 이름·날짜 칸 넣기
- 미로 번호: 번호가 같으면 똑같은 미로가 다시 나와요(정답지를 나중에 다시 뽑을 때 사용)
- 모든 미로는 길이 하나뿐인 완전 미로이고, 출발에서 도착까지 정답 길을 자동으로 확인해요

## 사용 방법
1. 테마와 난이도를 고르고, 몇 장 뽑을지 정해요
2. `새 미로`를 누르면 매번 다른 미로가 나와요
3. `프린트하기` → 용지 A4, 배율 100%(또는 기본)로 출력해요. PDF로 저장하려면 프린터를 'PDF로 저장'으로 바꿔요

## exe 버전 안내
- 설치하지 않고 더블클릭하면 바로 열려요. 인터넷 연결이 없어도 되고 개인정보를 수집하거나 보내지 않아요.
- 프로그램 안에 든 화면 파일을 `%LOCALAPPDATA%\BetaDadMazeFactory`에 풀고, Microsoft Edge(없으면 Chrome)의 앱 창으로 열어요.
- 인증서 서명이 없는 개인 제작 프로그램이라 처음 실행할 때 'Windows의 PC 보호' 창이 뜰 수 있어요. `추가 정보` → `실행`을 누르면 열려요. 걱정되면 위의 웹버전을 쓰세요.
- 받은 파일이 원본인지 확인하려면 Releases에 적힌 SHA256 값과 비교하세요: PowerShell에서 `Get-FileHash .\베타아빠미로공장.exe`

## 이용 안내
- 가정·어린이집·학교 수업에서 무료로 쓰세요. 만든 미로 도안은 자유롭게 출력해 나눠 주셔도 돼요.
- 프로그램 파일을 다른 곳에 올리거나 판매하지 말아 주세요. 공유할 때는 이 페이지나 블로그 링크로 알려 주세요.
- 글꼴: 주아체(Jua, SIL Open Font License 1.1, `Jua-OFL.txt`)를 필요한 글자만 줄여서 넣었어요.

## 직접 빌드하기
- `build-web.ps1`: `src/app.html`에 주아체 일부 글자를 넣어 `index.html`을 만들어요(Python fontTools 필요)
- `build-exe.ps1`: 윈도우에 들어 있는 .NET Framework 컴파일러(csc)로 `dist/베타아빠미로공장.exe`를 만들어요
